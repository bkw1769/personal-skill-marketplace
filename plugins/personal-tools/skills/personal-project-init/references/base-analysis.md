## AGENTS 규칙과 적용

- 모노레포: 필요한 서브레포는 루트 디렉터리로 분리한다.
- 응답: 한국어. 코드·주석·문서는 기본 영어이며 다른 언어를 금지하지 않는다.
- 사용 내역: 최종 응답 첫 줄에 사용한 스킬·MCP 등의 이름과 실제 읽은 파일을 명시한다.
- 문서: DECISIONS는 지속적인 동작/계약의 이유, MEMORY는 짧은 참조, STRUCTURE는 경로의 목적을 담는다. 루트와 서브레포 README에 실행 안내를 둔다.
- 변경과 문서: 동작·계약·스키마·워크플로 변경 시 관련 문서도 갱신한다.
- 테스트: 서브레포별 단위 테스트와 루트 통합 실행, 모든 코드 경로와 100% 커버리지를 요구한다. 뼈대 생성만으로 검증이 완료되지는 않는다.
- 규약: 공개 시그니처에 타입 명시, 요청 없는 이모지 금지, 동작 변경과 테스트를 같은 작업에서 처리한다.
- 스택 의존 규약: 실제 언어를 선택한 후 각 서브레포의 명명법과 타입 표기를 결정한다. 미정이면 TBD를 유지한다.

## 원본 보존과 갱신

`assets/AGENTS.md`는 분석 시점 원본의 정확한 사본이다. 초기화 시 원본 경로에 접근할 필요가 없다. 기준이 바뀌면 사용자의 스킬 갱신 요청에서 원본을 다시 읽고 사본과 이 분석을 함께 갱신한다. 생성 중에는 base 자체나 전역 project-init 스킬을 바꾸지 않는다.
