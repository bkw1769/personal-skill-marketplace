# Shorts upload sheets

One `publish.json` per episode is the source of truth. The script turns it into three sheets the user copies from when uploading:

| Sheet | Main block | Hashtags |
|---|---|---|
| `youtube.md` | title (+ other titles), description | all of `publish.hashtags` (max 15) |
| `tiktok.md` | caption: title line as hook + description | 5, YouTube-only tags such as `#쇼츠` dropped |
| `instagram.md` | caption: title line as hook + description | 5 (Instagram's cap since Dec 2025) |

Every sheet gets the same source list (from shorts-research, web addresses left out because the links are not clickable), the AI disclosure, the channel's correction line and a checklist.

Do not edit the sheets by hand: the next run would lose the edit. Change `publish.json` or the channel file and run again. The script refuses to overwrite a sheet that it did not write, unless `--force` is passed.

## When to run

- **Right after every export or re-export of the video.** Length, numbers and sources may have changed.
- After any change to the title, description, hashtags, cover, facts or storyboard.

## Inputs

1. `src/shorts/episodes/<id>/publish.json` (format below).
2. `research/sources.json` and `research/facts.json` (shorts-research).
3. `storyboard.json` (captions and overlays with `claims`; `duration` in seconds).
4. Optional: `thumbnail.json` (its numbers are traced too), `sources.txt` (where the URLs live).
5. Optional channel defaults `--channel <channel.json>`:

   ```json
   {
     "schema": "shorts-channel/1",
     "name": "궁금인간",
     "language": "한국어",
     "category": "교육",
     "correction": "틀린 내용이 있으면 댓글로 알려 주세요. 확인한 뒤 고정 댓글로 바로잡겠습니다.",
     "first_comment": "다음엔 어떤 게 궁금하세요? ...",
     "youtube_only_hashtags": ["#쇼츠", "#shorts"]
   }
   ```

### publish.json

| Field | Required | Use |
|---|---|---|
| `title` | yes | List; the first is used, the rest are listed as alternatives on YouTube. No "<" or ">" (required, see below). |
| `title_claims` | if the title has a number | Claims for the title (traced). |
| `description` | yes | List of lines. The same lines go to all three platforms. No "<" or ">": write a menu path as "설정 → 배터리 → 충전", never "설정 > 배터리" (required, see below). |
| `hashtags` | yes | Channel tag first. Put YouTube-only tags last; TikTok and Instagram take the first 5 others. |
| `disclosure` | yes | AI picture and voice notice. |
| `made_for_kids` | yes | YouTube audience setting. |
| `name` | no | Short episode name for the sheet heading (default: folder name). |
| `cover` | no | `{ "at": 30.5, "note": "점은 36개" }`: frame to pick when a custom cover cannot be uploaded. |
| `tags`, `playlist` | no | YouTube tags and playlist. |
| `first_comment` | no | Overrides the channel's first comment for this episode. |
| `altered_content` | no | `true` only for realistic synthetic people, places or events (YouTube setting). |

## Run

```bash
node <skill-dir>/scripts/upload.mjs src/shorts/episodes/<id> --out src/shorts/out/<id>/upload --channel src/shorts/channel/<kit>/channel.json
```

- `--video` and `--thumbnail` default to `<id>.mp4` and `<id>-thumbnail.png` next to the upload folder.
- **Required for YouTube: no angle brackets.** YouTube refuses "<" and ">" in the title, description and tags, so the upload fails on them (user rule, 2026-10-21). The script stops with an error when the YouTube title, description (summary, source list, closing lines, hashtags) or `tags` contain one. Fix it where it comes from: `publish.json`, or a source title in `research/sources.json` (cite copies titles into the source list). Use "→" for menu paths and words or 「」 for quotes; corner brackets 「」 and quotes are fine.
- **Exit 1** means nothing was written. Fix the errors it prints: an untraced number, a missing title or description, a length over a platform limit, a video over 3 minutes, a hand-written sheet in the way.
- **Numbers trace cannot read** (stage card rows, compare labels, timer counts, a number's sub line, buckle labels) get an unchecked box in every sheet and a table "직접 대조할 화면 숫자" in `youtube.md`. Read each against `research/facts.json` with the user; a row without claims is marked **없음**.
- **Warnings** still write the sheets. They become unchecked boxes in the checklist: no fact review, a single-source claim, a missing video file, no cover frame.

## After running

Read the three sheets once. Then tell the user, in their language:
- where the sheets are;
- what the checklist still needs from them, usually the fact review and the cover choice;
- the video length against the platform rules: TikTok Creator Rewards needs over 1 minute; Shorts and Reels allow 3 minutes.

Platform rules and their sources: `references/platforms.md`. Check them again when a platform changes its limits, then update `LIMITS` in the script and its tests together.
